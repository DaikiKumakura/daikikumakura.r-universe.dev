# DaikiKumakura.r-universe.dev

Registry for the [R-universe](https://r-universe.dev/) of Daiki Kumakura (`https://daikikumakura.r-universe.dev`).
`packages.json` lists the R packages built there:

- [pkident](https://github.com/DaikiKumakura/pkident): structural and practical identifiability for PK/PD ODE models built on rxode2
- [rsemflow](https://github.com/DaikiKumakura/rsemflow): downstream bulk RNA-seq analysis of RSEM gene-level results
- [retiaudit](https://github.com/DaikiKumakura/retiaudit): inspect Python selection hints for reticulate without starting Python

More about the software: <https://daikikumakura.github.io/software.html>
